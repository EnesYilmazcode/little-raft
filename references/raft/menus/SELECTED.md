# Raft reference: menus (selected stills)

Internal study only. Raft is by Redbeet Interactive; never copy these into `dist/`.

The network was blocked (YouTube, Steam, raft.wiki.gg and Wikimedia were all unreachable), so this selection was made from stills already on disk under `references/raft/`. No images were copied or duplicated; every path below points to the existing file. Ranked best first.

Source URLs come from each folder's `SOURCES.md` or `rows.json`. For press stills the image URL is given, followed by the Steam news post it came from. For `building/yt` frames the video URL is from `SOURCES.md`, with `t=` added from the `<videoid>_<mmss>` filename (approximate). `inventory-crafting/yt` has no provenance file, so those URLs are built from the video id and timestamp in the filename.

Topic coverage: main menu, settings (in game and standalone), the hammer build menu (category column with flyout variants and a cost card), the paint-brush colour menu, research table, notebook, NPC dialogue box.

## Coverage gaps

- No pause/escape menu as such (Resume / Save / Quit list). #5 is the nearest: settings opened during play.
- No new-game screen (world name, game mode and difficulty picker), no load-world list, no join-world or character screen.
- No loading screen, death or respawn screen, or credits.
- Settings has only the General and Graphics tabs; Controls and Audio are not shown.
- The build menu is Raft's L-shaped column-plus-flyout panel, not a radial; all build-menu frames are 480p video grabs except #7.
