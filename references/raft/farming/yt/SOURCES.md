# Raft farming reference frames (YouTube)

Reference stills of the real game Raft (Redbeet Interactive) covering farming, for internal study only. Not game assets. Never copy anything from this folder into `dist/`.

Frames were extracted at 480p or lower and picked by hand. The source videos have since been deleted from YouTube, so the links below are kept only as a record of where each frame came from; they are not expected to play.

File names are `<videoid>_<mmss>.jpg` (the same convention as `building/yt/`): the four digits are minutes and seconds, so `_0110` is 01:10 (70 s). Timestamps are approximate (within a few seconds).
