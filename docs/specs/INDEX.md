# Raft-feel specs: index and merged change list

**Purpose.** This page merges the 13 verified study docs into one ranked plan. Each doc compares stills of Raft (Redbeet Interactive) with Little Raft (`dist/`). The goal is for Little Raft to feel like a game in the Raft genre: a small raft on a bright ocean, a hook and rope, floating debris, building, crafting and farming. Every value below is the skeptic's CORRECTED value where one exists.

**Media.** All media came from stills already in `references/raft/`. The sandbox network blocked YouTube, Steam and raft.wiki.gg in this run, so no new frames were collected for **hud, hook-early, viewmodel, world or menus**. Those topics use curated `references/raft/<topic>/SELECTED.md` lists instead. Anything that came from the wiki or from memory is tagged UNSURE in the source docs.

**Originality guardrail.** Little Raft is an original game. Copy layout, proportions, timing and feel only. Never copy Raft's art, logo, icons, fonts, UI skin (parchment, plank frames, key-cap art) or creature designs. Hex values from Raft are reference ranges, and each change picks its own colours inside them. README.md says the game has no hunger or damage by design, so stat-bar and shark findings are layout notes or owner decisions, not requests.

## Bugs found along the way

These are real defects in today's `dist/`, separate from the design changes.

1. **Crosshair is 13 px up and left of the aim point.** `style.css:7` `margin:-13px 0 0 -13px` and `graphics.css:208` `transform:translate(-50%,-50%)` both apply. At 1280x720 the reticle centre renders at (627, 347) while aiming uses NDC (0,0) (`game.js:488`). The `style.css:9` `::before` ring also sits just inside the 1 px border, so the two read as one ring about 3 px thick. Fix: drop one offset. (hud, Playwright-confirmed)
2. **`sky.js`, `waterfx.js` and `rope.js` are never imported.** No static or dynamic import in any `dist/*.js`, and `index.html` loads only `live.js` and peerjs. So there is no sky gradient, sun, splash or rope tube in game. (world, colour-lighting, hook-early, materials)
3. **Vertex colours written as sRGB into linear attributes.** Three.js r170 (`vendor/three.module.js`), colour management on, output sRGB. `debris.js:232` (steel shows #d0dde7, rust #bc8659, orange #dfaa73), `plastic.js:48` (grime washed out) and `rope.js:12-13, 62` (rope shows as cream). Fix: `new T.Color().setRGB(r, g, b, T.SRGBColorSpace)` and write `.r/.g/.b`, or the instance method `new T.Color(r, g, b).convertSRGBToLinear()`. There is no static `T.Color.convertSRGBToLinear` in r170 (CORRECTED). Visible today on the scrap sheet and plastic jug only. (materials #2)
4. **Notices are suppressed while the inventory is open.** `game.js:403` `if (running && !dialog)`, with `dialog = uiBlocked()` (`:231`, `:822`). A craft inside the bag shows nothing; its 1.8 s notice expires unseen. (inventory-crafting)
5. **The recipe list hides 2 rows.** `.sv-craft` `max-height:min(520px, 94vh-30px)` (`survival-ui.js:145`), rows 58 px at a 64 px pitch: scrollHeight 652. Exactly 2 of 10 recipes are below the fold at 720p and 1080p. (inventory-crafting, rendered)
6. **`onPause` does not pause solo play.** `game.js:1183` only calls `clearInput`, so drift and the hook keep simulating under "Paused". (menus #5)
7. **Hands bob at 1.7 Hz, the camera at 1.43 Hz.** Hand vertical bob `0.5-0.5cos(2ph)` with `ph = t·2π·0.85` (`hands.js:230, 232`). Camera `walkPhase += dt·9·min(1.6, speed/2.6)` (`game.js:689`, applied at `:716`): 1.43 Hz walking, 2.20 Hz sprinting. They never lock. (viewmodel, camera-fov)
8. **A loot notice hides the next pickup prompt.** `updateContext` (`game.js:401-412`) shows notices before "E Pick up", and loot (`:562`) holds the slot for 1.8 s (`:394`). Net catches are silent (`:556`). (hud, ui-typography)
9. **The build crosshair rule is dead.** `style.css:10` `body.build #crosshair i`, but `body.build` is only ever removed (`game.js:264`). (building #8)
10. **The build ghost ignores raft roll and floats.** It is in `scene` at `raft.position.y + .29` (`game.js:811`), not in `raft`, so it ignores `raft.rotation` (`:291`) and sits above the deck top (FLOOR_TOP .2). It also vanishes when invalid instead of turning red (`:499-505, 810`). (building)
11. **The ocean does not follow the camera.** `followCamera` is unset at `game.js:290`, so `ocean.js:197-201` never runs. A swimmer 15 m or more from the origin brings the 140 m edge inside the 125 m fade. This is arithmetic, not observed. (world #6)
12. **Loaded web fonts barely reach the game.** Outfit (`style.css:1`) is used nowhere after `graphics.css:376`; DM Sans reaches only `.guide kbd`. The HUD falls back to Bahnschrift (Windows only) or Arial. (ui-typography)
13. **Eye height constants disagree.** `avatar.js:158` 1.65 vs `player-physics.js:13` and `game.js:37` 1.6, so the remote head is 5 cm off the camera. (model-proportions #7)
14. **Sphere clouds render as dark teal blobs** (#194b44, V .29) from below, because of the hemisphere ground colour (`game.js:288, 301`). (colour-lighting)
15. **Prompt text falls below 4.5:1 over white sky.** `#contextPrompt` 3.46:1 and the aim hint 3.43:1. A disabled recipe's `opacity:.6` cuts the short-ingredient colour to 2.9-3.4:1. (ui-typography)
