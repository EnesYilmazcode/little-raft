Little Raft perf lab

Every number below comes from the real game in dist/, profiled headlessly by sandbox/perf/shoot.py. Each fix is applied to the live scene in a fresh page with a seeded world, so all scenarios see the same sea. SwiftShader rasterises on the CPU, so the GPU-process CPU ms column stands in for GPU cost. It is a relative measure only. Submit ms is the main-thread time inside renderer.render (JS + WebGL command encoding), and it is the number that matters on real hardware. The machine was shared with other agents (load average about 30 on 4 cores), so wall-clock frame times are meaningless and are not shown.
